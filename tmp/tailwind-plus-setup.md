# Tailwind Plus

## Goal
For the development of the MIA frontend, Tailwind Plus must be used. 
Tailwind Plus is a paid service and access to its documentation requires a user name and password.
The subscription has been bought. Username and password is stored in `./tailwind-plus-credentials.txt`.

The repository, rules, skills and MCPs must be prepared, so LLM based agents (BMAD) have full and efficient access
to Tailwind Plus to use the components during development.
